### `psiwatch` &nbsp; — &nbsp; ML drift detection

<a href="https://pypi.org/project/psiwatch"><img src="https://img.shields.io/pypi/v/psiwatch?style=flat-square&color=00E5FF&labelColor=0D0D1A&label=pypi" /></a>&nbsp;<a href="https://pypi.org/project/psiwatch"><img src="https://img.shields.io/pypi/dm/psiwatch?style=flat-square&color=7C3AED&labelColor=0D0D1A&label=downloads%2Fmonth" /></a>&nbsp;<img src="https://img.shields.io/badge/dependencies-zero-00E5FF?style=flat-square&labelColor=0D0D1A" />&nbsp;<img src="https://img.shields.io/badge/runs%20on-Termux%20%7C%20Colab%20%7C%20anywhere-7C3AED?style=flat-square&labelColor=0D0D1A" />

detects when your production data drifts away from training — before your model silently breaks.  
PSI · Chi-Square · mean shift. ~15KB. zero deps.

```bash
pip install psiwatch
psiwatch compare train.csv prod.csv --output report.html
```
